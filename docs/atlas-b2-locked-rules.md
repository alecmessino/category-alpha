# Storm Atlas — B2+ locked rules (accepted end of turn 3)

Architecture: **B2** plate + ledger, carried by **E** every row is a lens.
Governing law: **Inspection changes the view. Commit changes the answer.**
`3j` remains the interaction contract.

## Locked geometry discipline (do not reopen)
- A coordinate readout is legal only inside the plate's stated aperture. Off-plate reads `—`.
- Genesis rings and scale bars are the projected 500 km, computed from the plate's own
  aperture and centre latitude. One rule for engineering.
  (Cohort plate 118°W–48°W, centre 26.9°N. East Pacific plate 168°W–98°W, centre 22.3°N.)
- East Pacific questions use the EP plate, which actually contains 145°W. Never place an
  EP ring on the NA+EP cohort plate.
- Reticles that mark a point make no distance claim.
- Lens inks are rendered, not asserted: POPULATION_INK `#7a9cbb`, EMPHASIS_INK `#cfe6fa`,
  class colour, MAJOR_WEIGHT 1.35, cased overlap.
- A lifted subset on the plate is illustrative density. Published counts live only in the
  ledger. The plate may not invent 470 tracks to match a row.
- Tracks remain placeholder until the engine supplies canonical member IDs.
- Dark plate in the paper shell is locked. Light/paper belongs to CITE/export (Direction C).

## Locked interaction rules
- Holds are view state. They never write rates, cohort, citation, or URL.
- The query sentence is the only publishing surface. Only commit writes the URL.
- Reverse storm → ledger membership is inspection only.
- Clause edit may preview geometry and a preview count from the canonical query path.
  Evidence stays frozen and labelled frozen until commit.
- Multi-row inspection may show canonical member sets. It never creates a new statistical
  answer. Overlap publishes nothing.
- Nested / containing thresholds cannot be co-held.
- `SCORE THIS AS A COHORT →` opens the clause editor unset.
- Limits stay pinned at the ledger foot. Promotion is presentation priority only.
- The renderer never reproduces statistical predicates. Membership consumes canonical
  member IDs from the engine.

## Turn 4 scope — finish the resting instrument first, then annotate. Add no states.
1. **Resting frame (do first).** Question wins the page at ~28–30px serif. Empty
   genesis/outcome/scope states are pressable clauses *in the sentence* — not
   `GENESIS-SIDE NONE · OUTCOME-SIDE NONE`. The sentence must read before any condition
   exists. Cohort count has one primary home, a quiet line under the question:
   `3,885 of 3,959 archive storms · sufficient sample`. Captions may echo N; no third
   headline 3,885. Masthead recedes — METHOD · CALIBRATION · PROVENANCE · CITE stay
   available and must not compete with question → cohort → plate → evidence.
   Evidence columns: `OUTCOME | n / N | RATE | 95% WILSON`. Wilson interval in type is
   canonical. A thin magnitude hairline is allowed; a wide bar plus a separate interval
   is not.
2. **Lens (first shipping interaction).** One held row. Hover/focus = transient lift.
   Click/keyboard = sticky hold. Release = exact restore. URL unchanged. Plate footer may
   echo that row's already-published figures; it computes nothing. Human language, not
   `VIEW · NONE HELD`: "Looking at Category 4 — question unchanged."
   Two-row hold is a later increment: specify, do not hero. Cap at two rows, different
   families only. Basin-density test stands before dual-colour overlap drawing; fallback
   is set emphasis + a legend that overlap exists. Keep cased-overlap render as reference,
   not a shipping requirement.
3. **Selected storm.** Does not replace the ledger. Minimum strip only: name / ID / year /
   basin; archive peak / min P; `COUNTED IN 5 OF 6 INTENSITY ROWS`; Build cohort around
   this genesis; Dossier link if one exists. Keep the derived plate-local ladder.
   Two-clock operational/archive reconciliation stays in the Dossier and does not leak
   into the resting ledger.
4. **Promotion.** PROMOTE UNKNOWN when the unknown population exceeds at least one
   positive published numerator. If every relevant published numerator is zero, use a
   separate zero-event / unknown-dominant case. Do not say unknown storms "could change
   the conclusion." One concise line near the question, one SEE THE ROW, full limits block
   still at the foot. Draw that line beside the finished 28–30px question before locking type.
5. **Below-minimum.** The mock's withheld values are not the product rule. Real
   below-minimum cohorts show real N, real numerators, and the refusal. Refuse only what
   methodology marks unpublishable. Refusals in Atlas/Lala editorial language, never
   Terminal dialect.
6. **Responsive.** 768/760 is the same instrument stacked — not a second product and not
   proof mobile is solved. Specify resting, clause edit, one hold, selected storm, and
   promoted limitation at 768. Add 390px frames for clause edit and one hold. Do not
   shrink the desktop composition.
