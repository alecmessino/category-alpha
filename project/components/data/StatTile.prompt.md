**StatTile** — hero KPI or command-rail metric. Mono tabular value, dimmed unit, uppercase label.

```jsx
<StatTile label="Gulf SST Anomaly" value="+2.4" unit="°C" color="var(--warn)" sub="warm Gulf → RI fuel" />
<StatTile variant="metric" label="WIND" value="108" unit="kt" sub="NHC advisory" />
```
